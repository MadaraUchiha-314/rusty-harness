# A2A extension: participants/v1

- **URI:** `https://madarauchiha-314.github.io/rusty-harness/a2a/ext/participants/v1`
- **Schema:** [`v1.schema.json`](./v1.schema.json) (JSON Schema, generated from the Rust
  types and contract-tested against `specs/a2a-ext/participants.v1.schema.json`)
- **Rides on:** `Task.metadata`; a message's `metadata.participant` names the sender when
  the caller acts for one

## What it carries

Everyone on the task: each participant's id, display name, kind (person or agent) and roles (admin,
assignee, reporter, watcher). The server shows a task to its participants only; a caller names the
participant it acts for with the `x-rusty-harness-participant` header.

## Activation

Send `A2A-Extensions: https://madarauchiha-314.github.io/rusty-harness/a2a/ext/participants/v1`
(several URIs comma-separated) on a request; the server applies the extensions it
advertises and echoes them in the response's `A2A-Extensions`. The metadata key is the
URI itself. Back to [all extensions](../).
