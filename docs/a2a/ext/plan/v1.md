# A2A extension: plan/v1

- **URI:** `https://madarauchiha-314.github.io/rusty-harness/a2a/ext/plan/v1`
- **Schema:** [`v1.schema.json`](./v1.schema.json) (JSON Schema, generated from the Rust
  types and contract-tested against `specs/a2a-ext/plan.v1.schema.json`)
- **Rides on:** an artifact of media type `application/vnd.rusty-harness.plan+json`, `TaskStatus.message.metadata`

## What it carries

The agent's plan as a DAG: steps with their status and output, edges between them, and the tasks
each step links to. Persisted and re-rendered on every change, so a renderer can show progress
without reading the history.

## Activation

Send `A2A-Extensions: https://madarauchiha-314.github.io/rusty-harness/a2a/ext/plan/v1`
(several URIs comma-separated) on a request; the server applies the extensions it
advertises and echoes them in the response's `A2A-Extensions`. The metadata key is the
URI itself. Back to [all extensions](../).
