# A2A extension: commands/v1

- **URI:** `https://madarauchiha-314.github.io/rusty-harness/a2a/ext/commands/v1`
- **Schema:** [`v1.schema.json`](./v1.schema.json) (JSON Schema, generated from the Rust
  types and contract-tested against `specs/a2a-ext/commands.v1.schema.json`)
- **Rides on:** the agent card's extension `params`, `Message.metadata`

## What it carries

On the card: the slash commands the agent accepts (`/exit`, `/model`, `/effort` and whatever plugins
add), each with a description key and the roles allowed to invoke it. On a message: the command
tokens the harness recognised in a person's text, and the outcome once run. Commands are parsed from
people's messages only, never from tool results.

## Activation

Send `A2A-Extensions: https://madarauchiha-314.github.io/rusty-harness/a2a/ext/commands/v1`
(several URIs comma-separated) on a request; the server applies the extensions it
advertises and echoes them in the response's `A2A-Extensions`. The metadata key is the
URI itself. Back to [all extensions](../).
