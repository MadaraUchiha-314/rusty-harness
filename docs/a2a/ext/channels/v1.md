# A2A extension: channels/v1

- **URI:** `https://madarauchiha-314.github.io/rusty-harness/a2a/ext/channels/v1`
- **Schema:** [`v1.schema.json`](./v1.schema.json) (JSON Schema, generated from the Rust
  types and contract-tested against `specs/a2a-ext/channels.v1.schema.json`)
- **Rides on:** `TaskStatus.message.metadata` for an ask, `Message.metadata` for the reply

## What it carries

A question the agent asks named participants through a channel the harness owns: the channel and ask
ids, the addressees, and whether the question is plain text or an A2UI surface (A2UI rides on its
own extension, `https://a2ui.org/a2a-extension/a2ui/v0.9.1`). Members of the channel see the
question; other subscribers see the state change only. A reply is a message on the channel naming
the ask.

## Activation

Send `A2A-Extensions: https://madarauchiha-314.github.io/rusty-harness/a2a/ext/channels/v1`
(several URIs comma-separated) on a request; the server applies the extensions it
advertises and echoes them in the response's `A2A-Extensions`. The metadata key is the
URI itself. Back to [all extensions](../).
