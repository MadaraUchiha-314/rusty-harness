# rusty-harness-cli

The `rusty-harness` binary, as a native wheel per platform. Install it with the SDK as
`pip install "rusty_harness[cli]"`, or alone:

```sh
pip install rusty-harness-cli
rusty-harness            # first run writes ~/.rusty-harness/config.toml and opens the TUI
rusty-harness serve      # the A2A server
```

See the [documentation site](https://madarauchiha-314.github.io/rusty-harness/).
